# STORY · 城市空气质量监测看板（答辩版，7 页）

## ① 用户意图对齐

- **目标受众**：课程答辩现场——任课老师 + 同班同学。老师按验收标准打分，关心「功能是否齐全、数据是否真实、代码是否分层清晰、能否解释核心代码」；同学关心「长什么样、能不能跑」。
- **核心目标**：讲完后观众相信三件事——① 数据来自中国环境监测总站的真实观测，不是模拟数据；② F1~F8 八项前端功能与 A1~A4 四个接口全部落地，前后端联通；③ 自己能解释核心代码（AQI 国标换算、分层结构、清洗规则）。
- **PPT 长度**：7 页（老师要求 5~8 页）。Hero 配额 2 页（封面、结束页），占 28.6%。
- **视觉调性**：清新、澄澈、理性、数据感——天蓝 + 湖水青呼应"空气"主题。
- **内容边界**：
  - 必讲：项目背景与目标、真实数据来源与规模、技术架构与分层、F1~F8 + A1~A4 实现情况、数据结论、总结。
  - 不讲：环境踩坑细节、任务编号流水账、与验收无关的细节。
  - 禁碰：不把静态数据集说成实时数据（数据集截止 2025-12-31，页面已注明）。
  - **如实呈现技术栈**：当前实现为 Spring Boot 3.2 + MyBatis + MySQL 8 + Vue 3 + ECharts；与老师要求中「原生 HTML + CSS + JS」「JPA / MyBatis-Plus」的差异，需在答辩时口头说明，页面不作与实现不符的表述。

## ② 页面布局骨架

- **页面总数与分章**：7 页，不设目录页与章节扉页（页数紧张，直接进内容）。
- **Hero 页定位**：01（封面）、07（结束页）。中间 02~06 均为 Supporting；04、06 为视觉重页（peak 节奏）但不抬升为 hero，以守住 20~30% 配额。
- **rhythm 曲线**：01 peak → 02 valley → 03 valley → 04 peak → 05 valley → 06 peak → 07 peak。无连续三页 valley。
- **非对称版式预算**：5 / 7 = 71%（02、03、04、05、06）。
- **对称版式预算**：2 页（01 封面、07 结束页）；`N卡片横排` 全篇 0 次。
