# DESIGN · 城市空气质量监测看板（答辩版，7 页）

风格依据：用户选择「清新蓝绿」——天蓝 + 湖水青 + 浅灰，契合空气质量主题。未命中学术 / 咨询 / 政务预设分支，走通用设计原则 + 用户指定色相。

## 1. 画布与母版

- 画布 1280 × 720；内容页 padding 上 20 / 下 20 / 左 70 / 右 70。
- A 标题区 y=20→130（110px）：主标题 36px bold `#0E7490` + 下方 56×4 短横 `#7FD1C6`。
- B 内容区 y=150→660（**510px**）：正文、图表、SVG、卡片，不得越界。
- C 页脚区 y=660→700（40px）：左「城市空气质量监测看板」14px `#94A3B8`，右页码 `NN / 07`。
- 封面（01）与结束页（07）为全幅版式，padding 0，省略 A 区标题块。

## 2. 色彩

| 角色 | HEX |
|---|---|
| 背景 | `#F4F9FA` |
| 主色 | `#0E7490` |
| 辅色 | `#7FD1C6` |
| 强调色 | `#F59E0B` |
| 文本主色 | `#1F2937` |
| 文本次色 | `#64748B` |

面积：主色 ≤ 55%，辅色 ≤ 25%，强调 ≤ 10%（Hero 页 15~18%）。

渐变：
- 卡片头 / 强调块：`linear-gradient(135deg, #0E7490 0%, #7FD1C6 100%)`
- 封面蒙版：`linear-gradient(90deg, rgba(8,47,61,0.88) 0%, rgba(8,47,61,0.55) 42%, rgba(8,47,61,0) 80%)`
- 结束页蒙版：`linear-gradient(180deg, rgba(8,47,61,0.45) 0%, rgba(8,47,61,0.78) 100%)`

卡片阴影：`0 4px 20px rgba(14,116,144,0.08)`。

数据页专用（AQI 六档，仅用于等级图形）：优 `#4CAF50` / 良 `#EAB308` / 轻度 `#FF7E00` / 中度 `#EF4444` / 重度 `#99004C` / 严重 `#7E0023`。
